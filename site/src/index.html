Requirements

Before you install.

Threadboard is an open-source preview. Here’s what it does today.

What do I need?

Codex desktop with plugin and MCP App support, the Codex CLI, and Node.js 22.13 or newer. The package includes the compiled app, so you don’t need npm or a build step to use it.

Will a card start a chat automatically?

Start in new chat opens Codex with a prepared task prompt. Send it to begin. You can also ask an existing chat to claim a card. A claim gives one chat ownership; it does not start work until you send the prompt.

What gets sent to a server?

Threadboard has no hosted backend and doesn’t sync boards or transcripts. When you ask Codex to work on a task, that task context uses your normal Codex model service and allowance. Local storage doesn’t make the model run offline.

Can I use it across multiple computers?

The current preview is for one device. It has local exports and database backups; it has no account or cross-device synchronization.

How ready is the preview?

Board opening has been confirmed in Codex. Backend, browser, performance, and installation checks run in CI. Native chat placement and full-view navigation recovery are still experimental. Read the current release notes.

Does it cost anything?

Threadboard is free and MIT licensed, with no board subscription or hosted backend to pay for. Task work still uses your existing Codex account and model allowance.
